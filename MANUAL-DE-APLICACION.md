# Manual de aplicación

## Antes de cada participante

1. Utilizar la misma computadora, navegador y teclado durante el piloto.
2. Cerrar notificaciones reales y aplicaciones que puedan interrumpir.
3. Verificar que el navegador permita almacenamiento local.
4. Abrir la app desde su URL, no como archivo suelto.
5. Explicar que deben utilizarse alias o iniciales, nunca nombres completos.

## Durante la sesión

- No ayudar a responder después de comenzar la práctica.
- Registrar externamente cualquier interrupción importante.
- No recargar ni cerrar la pestaña; los alias no se conservan después de una recarga.
- La pantalla completa es recomendable, pero no obligatoria.

## Después de la sesión

1. Descargar el JSON individual.
2. Abrir el modo investigador.
3. Verificar que la sesión figure como completa.
4. Al terminar la jornada, descargar el respaldo JSON y los dos CSV.
5. Mover los archivos al almacenamiento institucional aprobado.

## Exportaciones

- **CSV ensayos:** una fila por ensayo para análisis estadístico.
- **CSV resumen:** medianas y costes descriptivos por participante y condición.
- **Respaldo JSON:** sesiones, ensayos, evaluaciones y eventos completos.

## Advertencias

- La app no sincroniza resultados entre computadoras.
- Borrar datos del navegador elimina el almacenamiento local.
- El panel de investigador no tiene autenticación real.
- No utilizar esta versión para inferencias confirmatorias sin completar el pilotaje y el protocolo ético.
